How to make a pull zone (get a b-cdn.net link)
      

        1. Account. Sign up at bunny.net and open the dashboard at dash.bunny.net. Check bunny.net for the current trial and prices.

        2. Add the zone. In the dashboard use + Add then Add Pull Zone (it is also under CDN in the menu).

        3. Name it. Use letters and numbers only, for example funnycdn7. The name has to be one nobody else has taken. It becomes funnycdn7.b-cdn.net.

        4. Pick the origin. Choose Origin URL and paste one of these, then set the box above to match:

         • Your repo only: https://raw.githubusercontent.com/USER/REPO/main (use your branch name)

         • Any GitHub repo: https://cdn.jsdelivr.net (links look like zone.b-cdn.net/gh/user/repo@main/file)

         • Pages that must open as real pages: make a Storage Zone first (Storage in the menu, then Add Storage Zone, then upload your .html files), and choose Storage Zone as the origin instead.

        5. Tier. Pick Standard (or Volume) and press Add Pull Zone.

        6. Wait a minute for it to spread, then type the zone name in the box above and press Make b-cdn links.

        If a page shows as text or downloads (GitHub raw does this): open the zone, go to Edge Rules, add a rule that sets the response header Content-Type to text/html for .html files, or use a Storage Zone.

        If an old version keeps showing after you changed a file: open the zone, then Caching, then Purge Cache.

How to make a Bunny CDN pull zone
          
    
            
  1. Make an account at bunny.net and log in (there is a free trial, then it is pay-as-you-go).
    2. 
            
  2. In the dashboard open CDN and press Add Pull Zone.
    3. 
            
  3. Type a name. That name becomes your address: yourname.b-cdn.net.
    4. 
            
  4. Set Origin type to URL and enter the website the pull zone should copy from, for example https://your-site.com. Use a site that is yours or that you are allowed to host.
    5. 
            
  5. Pick the pricing zones (Standard is fine) and press Add Pull Zone.
    6. 
            
  6. Open https://yourname.b-cdn.net. Bunny fetches pages from your origin and caches them on its servers.
    7. 
            
  7. Optional: Hostnames lets you add your own domain and turn on free SSL. Caching sets how long files are kept, and Purge Cache forces fresh copies after you change your site.
    8. 
          

        
How to copy ("dupe") a Google Apps Script
          
    
            
  1. Go to script.google.com and open the project you want to copy.
    2. 
            
  2. Click the i (Project Overview) icon on the left, then Make a copy at the top right. The copy is a new project in your own account.
    3. 
            
  3. Open the copy and press Deploy → New deployment. Click the gear and choose Web app.
    4. 
            
  4. Set Execute as to Me and Who has access to Anyone, then press Deploy. Google asks you to authorize it the first time.
    5. 
            
  5. Copy the Web app URL. It looks like script.google.com/macros/s/…/exec, and every copy gets its own, so you can swap to a new one if an old one stops working.
    6. 
            
  6. After you edit the code, use Deploy → Manage deployments → edit → New version, or the URL keeps running the old code.
    7.
